Adapter Pattern

Mục đích: Cho phép các interface không tương thích làm việc cùng nhau.

Ứng dụng:

  • Data format conversion
  • Legacy system integration
  • Third-party library wrapper

Lợi ích:

  • Tái sử dụng code
  • Tương thích interface
  • Separation of concerns
Components:
  • Target: DataProcessor
  • Adaptee: XmlService
  • Adapter: XmlToJsonAdapter
  • Client: JsonService
